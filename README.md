# Student-Expense-Tracker
A simple and beginner-friendly Student Expense Tracker built using Python. This project helps students manage their daily expenses by recording spending, viewing expense records, and calculating total expenses.

📌 Project Overview
Managing daily expenses is important for students. This project provides a simple terminal-based application that allows students to keep track of their spending and understand where their money goes.

The application is developed using Python and focuses on basic expense management.

✨ Features
- ➕ Add Expenses: Record new expenses with relevant details.
- 📋 View Expenses: Display previously recorded expenses.
- 🧮 Calculate Total Expenses: Calculate the total amount spent.
- 💻 Terminal-Based Interface: Easy-to-use command-line application.

🛠️ Technologies Used
- Programming Language: Python
- Interface: Command Line / Terminal
- Development Tool: VS Code / Jupyter
- Version Control: Git and GitHub
